# QUADCAST Projection Mapper

純前端的瀏覽器投影映射工具。媒體、畫面擷取與校正設定都在本機瀏覽器處理，不會上傳到伺服器。

## 使用方式

1. 使用 Chrome 開啟網站，加入本機圖片／影片，或按「擷取畫面」選擇瀏覽器分頁、應用程式視窗或整個螢幕。
2. 新增投影面並指定來源，拖曳預覽畫面上的 TL、TR、BR、BL 四個角完成透視校正。
3. 如需不規則外框，切換「多邊形」，新增與拖曳節點建立三角形、五邊形、凹多邊形等遮罩（最多 32 點）。
4. 按「開啟投影輸出」，把新視窗移至投影機，再按「進入全螢幕輸出」。
5. `B` 切換全黑輸出，`G` 切換編輯格線。可匯出 JSON 備份校正設定。

瀏覽器安全規則要求每次工作階段重新選取本機檔案與畫面擷取來源；幾何校正會自動保存在 `localStorage`。

## 開發

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

正式輸出為 `dist/`，可直接部署到 Vercel。畫面擷取需要 HTTPS 或 localhost。
