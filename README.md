# QUADCAST Projection Mapper

純前端的瀏覽器投影映射工具。媒體、畫面擷取與校正設定都在本機瀏覽器處理，不會上傳到伺服器。

## 使用方式

1. 使用 Chrome 開啟網站，加入本機圖片／影片，或按「擷取畫面」選擇瀏覽器分頁、應用程式視窗或整個螢幕。
2. 先新增或選擇投影機，再為該投影機新增投影面並指定來源。每台投影機都有獨立的投影面清單與校正資料。
3. 拖曳預覽畫面上的 TL、TR、BR、BL 四個角完成透視校正；按住面內可移動整個投影面。
4. 選擇投影機後按「開啟投影輸出」，把該台的獨立輸出視窗移至對應投影機，再按「進入全螢幕輸出」。
5. 可同時開啟多台投影機輸出。`B` 會切換全部輸出的黑畫面，`G` 切換編輯格線；可匯出 JSON 備份所有投影機設定。

瀏覽器安全規則要求每次工作階段重新選取本機檔案與畫面擷取來源；幾何校正會自動保存在 `localStorage`。

## 開發

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

正式輸出為 `dist/`，可直接部署到 Vercel。畫面擷取需要 HTTPS 或 localhost。
